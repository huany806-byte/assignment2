Project Overview
I got the inspiration for this project from my Google Chrome tabs because I always forget to close them. Sometimes I have so many tabs open that I don't even remember why I opened them in the first place. I thought it would be interesting to see what types of websites take up most of my browser. Therefore, for this project, organized my tabs into different categories and visualize my browsing habits in a simple and interactive way. I organized 40 sample tabs into categories such as Entertainment, School / Work, Shopping, and Research / Tools.

The website uses Chart.js to display the data through doughnut and bar charts. Users can switch between categories and individual websites, and hover over the charts to see more information.

Tools Used
- HTML & CSS: Website structure and styling.
- JavaScript & Chart.js: Data visualization and interactive charts.
- AI: debugging, and troubleshooting.

Data
The project uses a fictional dataset of 40 Chrome tabs based on websites I commonly visit, including Bilibili, Canvas, Google Docs, and Amazon.
